# FPGA-Based Smart Watering System

A digital logic project designed and implemented using VHDL and FPGA concepts as part of my Computer Engineering coursework at Shiraz University of Technology.

## Overview

The system represents an automated watering controller based on environmental conditions such as soil moisture and temperature.

The design uses threshold-based logic to determine the watering state and provides visual indicators of the system status.

## Main Components

- VHDL-based digital logic
- Finite State Machine (FSM)
- Soil moisture and temperature threshold logic
- Clock and timing logic
- Seven-segment display
- LED status indicators

## System Behavior

The system monitors the configured environmental conditions and determines whether watering is required based on predefined thresholds.

The seven-segment display and LEDs are used to represent relevant measurements and watering status.

## Project Context

This project was developed as part of my undergraduate Computer Engineering coursework at Shiraz University of Technology.

The project focused on digital system design and VHDL implementation rather than physical deployment of the complete watering system.
